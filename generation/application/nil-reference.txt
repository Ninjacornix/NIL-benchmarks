Write a complete expr-v5 NIL program. Entry is function a with signature (s,s)=expression and i64 result. Parameters a,b are input/output path bytes. Helpers are b,c,d,... in line order. A bare letter is a parameter/local state; a(...) invokes a function, independent of parameter names. One function per line. No imports, assignments, statements, comments or return keyword.
Typed function headers: (s):s=expression for bytes->bytes; (v)=expression for buffer->i64; (s,i):s=expression for bytes,int->bytes. For all-i64 parameters use numeric arity: 1=expression or 1:s=expression. Types i=i64,b=bool,s=bytes,v=dynamic i64 buffer. Default result is i64; :s/:v/:b select other results.
Operators: + - * / (wrapping i64 except division traps), < <= > >= == != returning bool, lazy condition?yes:no. No integer truthiness, logical and/or, modulo or unary negation on expressions: use 0-x. Comparisons bind below arithmetic, ternary below comparisons; parenthesize nested ternaries. Functions/arguments are evaluated left to right. Call helpers normally: b(a).
Sequences: #a is length, a[index] is i64 element, a[index:value] returns a replaced immutable sequence. Indices are zero-based. Bytes must be 0..255. Quoted literals are UTF-8 bytes; escapes \n \r \t \0 \" \\ and \xNN insert exact bytes. No character type. a[index] cannot be used as a truthy condition.
Intrinsics: !read(path):s, !write(path,data):i64 bytes written, !out(data):i64, !bytes(length,fill):s, !buffer(length,fill):v, !concat(left,right):same sequence type, !slice(seq,start,length):same type copying slice, !format(i64):canonical decimal bytes, !parse(bytes):i64. !parse accepts no spaces, newline, plus sign, leading zeroes or negative zero. !write creates/truncates output, including empty data. No text splitting intrinsic.
Loops: @(initial_values;bool_condition;updated_values;result). Initial/update values are comma-separated. Condition, updates and finish see ONLY positional loop states a,b,c,..., not outer parameters. All updates use OLD state simultaneously. Carry outer values into state explicitly. Nested loops have fresh scopes. Types/count of update values must match initial states. Example @(3,0;a>0;a-1,b+2;b) returns 6. Function parameters and loop states both use positional letters but their scopes differ.
Complete generic copy-file example:
(s,s)=!write(b,!read(a))
